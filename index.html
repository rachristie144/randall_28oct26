1. What is e-Research?

1.1. High level definition

  • e-Research enables and facilitates †
    • computational- and data-intensive research, and
    • research using sensitive data
  • e-Research provides the infrastructure and platforms required by a wide-range of research areas
  • e-Research provides software development skills and specialist support to support cutting-edge research at KCL

† (This isn't quite encompassing-enough)

  • Research Data Storage (RDS)

2. Research Infrastructure/Platforms

2.1. CREATE

Computational Research, Engineering and Technology Environment (CREATE)

CREATE includes a traditional HPC environment

  • linux command line accessed using ssh
  • batch processing with slurm
  • wide range of scientific applications installed
  • ~18,000 CPU cores and ~400 GPUs available

2.2. CREATE OnDemand

Web-interface for accessing CREATE platform

  • command shell interface via web browser
  • Jupyter Lab notebooks
  • RStudio
  • Desktop environment

👉 https://hpc-web.create.kcl.ac.uk/pun/sys/dashboard/

2.3. CREATE AI

Deep Learning workflows are supported on CREATE through:

  • NVIDIA GPUs - incl. new AI+ Programme GPUs
  • popular training frameworks, PyTorch, TensorFlow, etc.
  • NVIDIA software stack

2.4. CREATE AI - 2

CREATE platform for S/LLM research:

https://ai.create.kcl.ac.uk

Not Chat-GPT/Claude, but has advantages for some areas of research:

  • data is kept local to KCL
  • different models can be installed, tested, augmented (SLMs) 🤗
  • e.g., use as reasoning engine for autonomous labs

2.5. Trusted Research Environment (TRE)

A Trusted Research Environment (TRE) is a highly secure digital platform that allows approved researchers to access and analyse sensitive data without the data ever leaving the secure environment.

TREs are becoming increasingly popular in research due to:

  • compliance requirements from funders & regulators
  • increased cyber security threat landscape
  • increased use of sensitive data in research

https://docs.er.kcl.ac.uk/CREATE/TRE/tre/

3. Development & support

3.1. Research Software Engineering (RSE)

The Research Software Engineering team can develop the software required to enable and facilitate your research.

The team have a wide range of experience and skills developing code for a range of academic disciplines.

Support is provided by:

  • consultation and advice
  • being costed into grants for hands-on dev work

The e-Research team can assist with project design and co-writing (for projects with computational-, data-science or sensitive data components)

4. Costing models & Governance

https://docs.er.kcl.ac.uk/costing_grants/

4.1. Organisational/budget structure

e-Research sits in the Research Management and Innovation Directorate (RMID) in Professional Services (PS).

We have a staff budget, and an annual capital budget for minor maintenance/hardware upgrades (from the Research Infrastructure Fund).

All software/licenses/warranties are paid through income from research grants

4.2. Free basic usage

Research Computing facilities & support are an essential and integral component of a research university.

For this reason, and to support student development skills and basic/PoC usage, e-Research facilities and support have free-to-use components:

  • HPC: free to use, resources shared with queue scheduler
  • RDS: free 5 TB per funded project
  • Private cloud/IaaS: small vCPU and memory projects

4.3. Costing model

Costing model based upon TRAC methodology; some components are TRAC-listed, and others aren't

  • pay-as-you-go GPU usage model (£0.12-£0.98 per hour)
  • GPU/CPU server hosting (£2,194-£3,275 per server)
  • RDS (£16.36-£60 per TB per year)
  • Private Cloud

More information at: https://docs.er.kcl.ac.uk/costing_grants/
